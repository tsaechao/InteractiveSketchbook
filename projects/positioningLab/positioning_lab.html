positioning elements

Static

default, as-is behavior

Relative

this positions a child relative to its parent. by giving an element a relative position, we can place it outside the normal flow of where it would be- but it still impacts other elements

Absolute

this takes the element out of the line up and no longer impacts elements around it, BUT you have to apply position:relative to a parent container

Fixed

positioned in relation to the browser window, it just stays put!

***Sticky***

this one is a little more advanced, and we won’t get into it yet, but perhaps challenge yourself and your project to see if you can figure it out?


Next up: z-index

this is how we control layering when we are using positioning. if an element has a position, you can add a z-index, the larger the number the closer to the top.
0=bottom 100=top
think of z-index like the “bring to front” or “send to back” in design software.

In this exercise, it's helped my understanding on how positioning can be adjusted and affect elements on a page. Finally understanding how relative, absolute and static positioning really affects how elements interact with each other on a page, I can go back and adjust pages where my alignment and positioning is a bit off and no longer have to go in blindly and experimenting every time. The z-index would also be really cool in a page where you want to layer several elements and think it can be useful for more “complex” pages. For the section, all I did was make the position static as I didn’t want to do anything crazy and found that making the position absolute made the header overlap and cover the content. As for troubleshooting, because I just followed the class lesson everything went by smoothly with the exception of the dots where I had to stray away from the instructions as they weren’t showing on my page with the sizing that the instructions listed. Overall, I think overusing positions can become really complicated quickly and you can easily lose track of all of your z-indexes, which is why creating parent containers makes it easier to keep track of elements and adjust them simultaneously.
