a visual guide to mid-century modern style

In this practice, it was extremely difficult for me to figure out the relationships of each element, how each command affects the whole layout and so many other things. Even now I'm not actually confident in what I have and there's still a lot that I need to learn and practice as of right now. The main issue I kept running into was figuring out the margins and padding of each box, sometimes if i clicked auto or messed with it slightly, it would remove the bullets on the list or de-center the navigation which was really frustrating to have to go back and fix. If I could change one more thing it would have to be the margin of the whole page. After this practice I have a slightly beeter understanding on how to tweak elements to achieve the look I need but as of now, I'm still not 100% satified with where I'm at.
